# 文档审查 MVP 测试说明

## 打开方式

双击项目根目录的 `打开信披智审_Windows.cmd`，或在本地服务运行时访问：

`http://127.0.0.1:8767/index.html#tasks`

## 测试步骤

1. 进入“审查任务”。
2. 点击“新建审查”。
3. 填写任务名称和审查类型。
4. 选择 `DOCX`、`PDF`、`CSV`、`TXT` 或 `MD` 文件并提交。
5. 等待本地解析完成，系统会自动进入文档审查工作台。
6. 点击右侧风险项，核对原文高亮、问题说明、依据和修改建议。

项目根目录提供 `测试文档_金额比例与表述风险.txt`，用于快速验证金额比例计算、确定性表述和完整性提示。

## 当前边界

- 单文件上限 20MB，文件只在本机内存中处理，不上传外部模型。
- 支持 DOCX、PDF、CSV、TXT、MD 和 JSON，不支持旧版 DOC。
- 扫描 PDF 使用 Windows 本地 OCR；加密或严重损坏文件仍需人工处理。
- 默认使用本地 BGE-M3、FAISS 和确定性规则，不调用外部 Embedding API，也不消耗 Embedding API Token。
- 完整性提示尚未绑定全部有效监管条款，只能作为待人工确认项。
- 最终披露、审批和合规结论必须由证券部结合最新规则及公司制度确认。
