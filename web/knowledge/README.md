# Knowledge Directory

This directory is the default import root for company knowledge. Runtime files
are intentionally ignored by Git because they may contain confidential data.

Supported logical categories:

- `company_profile`
- `regulations`
- `internal_rules`
- `announcements`
- `cases`
- `user_documents`

Use the application knowledge page or `web/scripts/import_knowledge.py`; do not
edit business code when adding company material.
